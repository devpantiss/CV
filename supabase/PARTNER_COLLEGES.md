# Partner Colleges

Admin → Partner Colleges (/admin/partners) manages the homepage Featured colleges & education partners section. College name and logo are required; city/location and HTTPS website are optional. Website links open in a new tab with noopener/noreferrer. Published entries appear publicly, drafts stay admin-only. Display order controls the list; lower values appear first. The homepage shows the first 18, with View all for the full list; it loads fresh data when opened/refreshed or focused. An intentionally empty published collection hides the section.

Storage reuses public.site_content with kind=partners, existing admin allowlist and RLS. The migration expands allowed kinds and adds partner-specific validation while preserving existing type validation. Local source: migrations/20261029105248_partner_colleges.sql; applied through the Supabase connector (remote timestamp may differ). Fifty-five existing homepage partners were imported with their original name, ordering and sprite logo positions. Editing details preserves those positions; uploading a replacement removes legacy positioning and uses a normal fitted image.

New logos upload through the existing admin-authenticated drive-upload function to the private app folder in Google Drive. Supported JPG/PNG/WebP, up to 5 MB; signed drive-media delivery reused. Old image files are not automatically trashed on replacement/deletion, following existing content behavior. Existing originals remain local public sprite sheets.
